# SpaceShmup26
Retro space hero game.

Game Description:

The player controls a spaceship and must survive waves of enemy ships while earning points by destroying them. The game features five enemy types with different health values, firing rates, and point rewards.

Controls:

W / Up Arrow: Move up
S / Down Arrow: Move down
A / Left Arrow: Move left
D / Right Arrow: Move right
Spacebar: Fire lasers

Game Features
- Five different enemy spaceship types
- Enemies that fire projectiles at the player
- Different enemy health values and firing rates
- Player shield system with four shields
- Laser shooting and enemy destruction
- Scrolling starfield background
- Score counter with different point rewards for each enemy
- Laser, explosion, and damage sound effects
- Start screen with a Start Game button
- Game Over screen displaying the final score
- Play Again button to restart the game

Scoring System:

Players earn points by destroying enemy ships. Larger enemies have more health and award more points.

Points:

Enemy_0: 100
Enemy_1: 200
Enemy_2: 300
Enemy_3: 400
Enemy_4: 500

How to Play:
1. Launch the game and click START GAME.
2. Move your spaceship using WASD or the arrow keys.
3. Press Spacebar to shoot enemy ships.
4. Avoid enemy ships and incoming projectiles.
5. Destroy enemies to increase your score.
6. Survive as long as possible with your four shields.
7. When all shields are lost, the Game Over screen displays your final score.
8. Click PLAY AGAIN to restart.
